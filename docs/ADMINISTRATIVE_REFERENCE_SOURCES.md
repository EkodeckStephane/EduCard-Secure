# Cameroon Administrative Reference Sources

The local demo reference for regions, departments and subdivisions is based on public administrative lists consulted online.

Sources consulted:
- Osidimbea, "Les communes du Cameroun", listing regions, departments, capitals, arrondissements and communes.
- Institut National de la Statistique du Cameroun, Annuaire statistique edition 2024, used to validate the national total of 10 regions, 58 departments and 360 arrondissements/communes.

Implementation notes:
- The data is a local reference dataset for demonstration and test flows.
- It does not contain personal data.
- It must be validated against an official MINESEC/MINAT institutional source before production use.
- Region, department and subdivision records include a `capital` field for chef-lieu display.
