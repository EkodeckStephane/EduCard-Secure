# Brouillon du modele de donnees

Le modele relationnel logique est organise par domaines : securite, referentiels, eleves, cartes, presence, services, paiements simules, incidents, exports, privacy et exploitation. La reference executable reste `backend/app/models/entities.py` et les migrations Alembic.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
