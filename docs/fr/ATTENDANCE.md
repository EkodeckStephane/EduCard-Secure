# Presence

Le module de presence gere entree, sortie, retard, absence, correction et validation. Aucune biometrie active n'est implementee ; toute extension biometrique necessiterait une analyse d'impact et une validation juridique.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
