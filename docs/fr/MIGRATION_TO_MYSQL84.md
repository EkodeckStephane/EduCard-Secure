# Migration vers MySQL 8.4 LTS

La migration cible reduit la dette MySQL 5.7. Le plan inclut sauvegarde, restauration de test, execution Alembic, verification des index, tests de non-regression et mise a jour documentaire.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
