# Registre des traitements

Le registre recense les finalites, categories de donnees, bases legales a valider, references de retention et statuts. Chaque finalite doit etre validee juridiquement avant donnees reelles.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
