# Brouillon d'architecture

Le brouillon initial retient une architecture modulaire : authentification, referentiels, eleves, cartes, QR, presence, services, paiements simules, tableaux de bord, exports, audit, incidents, sauvegardes et protection des donnees.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
