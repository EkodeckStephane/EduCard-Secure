# Alertes

Les alertes sont derivees des evenements de securite de criticite haute ou critique. Elles couvrent notamment les echecs de connexion repetes, les acces interdits, les changements de roles ou perimetres, la desactivation MFA, les QR invalides, les exports inhabituels, les ruptures de chaine d'audit et les incoherences de paiement simule.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
