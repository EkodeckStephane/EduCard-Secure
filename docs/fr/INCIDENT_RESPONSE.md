# Reponse aux incidents

Le workflow couvre creation, classification, priorite, affectation, commentaires minimises, analyse, containment, resolution et cloture. Les obligations de notification doivent etre validees humainement.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
