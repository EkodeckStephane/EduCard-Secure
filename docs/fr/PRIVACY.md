# Privacy by design

Le prototype applique minimisation, QR sans donnees personnelles directes, petits effectifs masques, RBAC, scopes, exports controles, demandes privacy, registre des traitements et retention brouillon.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
