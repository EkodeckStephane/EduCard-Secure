# Limitations connues

Le projet est un prototype non officiel avec donnees synthetiques, sans API externe, sans biometrie, sans HSM, sans WORM, avec MySQL 5.7 comme dette technique et i18n frontend limite aux libelles principaux.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
