# Authentification

L'authentification utilise Argon2id, sessions serveur, cookies HttpOnly, CSRF, rotation, expiration, revocation et MFA TOTP pour les roles privilegies. Les mots de passe et secrets ne sont jamais journalises en clair.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
