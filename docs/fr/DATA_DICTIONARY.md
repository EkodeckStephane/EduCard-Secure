# Dictionnaire de donnees

Le dictionnaire decrit les tables de securite, referentiels, eleves, cartes, QR, presence, services, paiements simules, incidents, exports, privacy, retention et sauvegardes. Les noms techniques restent alignes sur SQLAlchemy.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
