# Architecture

EduCard Secure est compose d'un frontend React/TypeScript/Vite, d'un backend FastAPI, d'une base MySQL 5.7 et de scripts PowerShell. Les controles d'autorisation sont appliques cote backend. Les secrets, cles, exports, logs et sauvegardes restent hors Git.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
