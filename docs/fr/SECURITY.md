# Securite

Les controles incluent Argon2id, sessions serveur, cookies HttpOnly, CSRF, RBAC, scopes, MFA, journalisation, QR Ed25519, exports controles, audit SHA-256, headers de securite et sauvegardes avec hash.

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
