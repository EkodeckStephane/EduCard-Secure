# Diagramme entite-relation

Le diagramme ER conserve les noms techniques anglais pour correspondre au schema SQLAlchemy. Les relations couvrent utilisateurs, roles, referentiels, eleves, cartes, presence, services, paiements, incidents et exports.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
