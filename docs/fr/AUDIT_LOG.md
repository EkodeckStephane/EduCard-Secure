# Journal d'audit

Le journal d'audit chaine les evenements sensibles avec SHA-256. Chaque evenement contient un identifiant opaque, un horodatage UTC, l'acteur, le perimetre, l'action, la ressource, le resultat, la justification et la criticite. Le prototype ne fournit pas de stockage WORM.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
