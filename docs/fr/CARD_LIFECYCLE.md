# Cycle de vie des cartes

Le cycle couvre demande, emission, activation, suspension, reactivation, revocation, remplacement, perte et dommage simules. Toutes les transitions sont controlees par RBAC, perimetres et journalisation.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
