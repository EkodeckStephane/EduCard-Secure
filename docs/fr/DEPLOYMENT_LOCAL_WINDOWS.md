# Deploiement local Windows

Le lancement local comprend creation de `.venv`, installation backend, configuration `.env`, migrations, seeds, lancement Uvicorn, installation frontend avec `npm.cmd` et demarrage Vite.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
