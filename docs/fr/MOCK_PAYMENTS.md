# Paiements simules

Les providers mock simulent MoMo, Orange Money, banque et guichet sans API externe, sans secret, sans donnees bancaires reelles. Les transactions sont idempotentes et journalisees.

## Statut

Document francais normalise pour la livraison locale. Les elements techniques conservent leurs identifiants originaux afin de rester verifiables dans le code et les tests.
