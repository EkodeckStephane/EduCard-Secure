# Documentation

EduCard Secure keeps language-specific documentation under:

- `docs/fr`: French documentation.
- `docs/en`: English documentation.

The historical files at the root of `docs` are kept for compatibility with
earlier phase references. New documentation should be added or updated in both
language directories.

## Maintenance Rule

When a document changes:

1. Update the French version in `docs/fr`.
2. Update the English version in `docs/en`.
3. Keep root-level compatibility files only when an existing script, test or
   phase instruction references them directly.
